# SS Book Editor PRO 📝

SS Book Editor PRO ek powerful aur lightweight web-based text editor hai jo aapko Microsoft Word jaisa experience deta hai. Isme aap documents likh sakte hain, unhe format kar sakte hain aur direct PDF mein download kar sakte hain.

## ✨ Features

- **MS Word Style UI:** Bold, Italic, Underline, aur Alignment ke saath professional Ribbon interface.
- **30+ Font Styles:** Likhavat ko sundar banane ke liye dheron fonts ka option.
- **Multi-Page Support:** Bilkul Wordpad ki tarah pages add aur remove karne ki suvidha.
- **Google Sheets Integration:** Naye users ka data (Name & Contact) direct aapki Google Sheet mein save hota hai.
- **PDF Export:** Apne kaam ko ek click mein professional PDF format mein save karein.
- **Responsive Design:** Laptop aur Desktop par behtareen kaam karta hai.

## 🚀 How to Use

1. **Registration:** Sabse pehle apna naam aur contact number daalkar register karein.
2. **Editing:** Toolbar ka use karke text ko edit aur format karein.
3. **Add Pages:** Agar zyada likhna hai toh '+ New Page' button ka use karein.
4. **Download:** Kaam khatam hone ke baad 'Save as PDF' par click karein.
## 🛠️ Technical Details
- **Frontend:** HTML5, CSS3, JavaScript
- **Libraries Used:** - [jsPDF](https://github.com/parallax/jsPDF) - PDF generation ke liye.
  - [html2canvas](https://html2canvas.hertzen.com/) - Screen ko image mein convert karke PDF banane ke liye.
- **Backend:** Google Apps Script (Data logging ke liye)
